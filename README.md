# Fibonacci Series in C

## Project files
- `fibonacci.c` — main C program.
- `fibonacci.docx` — project write-up (aim, algorithm, source code, sample output, result).
- `text.md` — short project notes.
- `data/input.txt` — sample input.
- `data/output.txt` — sample output.
- `README.md` — project overview and instructions.

## How to compile and run
Using GCC:

```bash
gcc fibonacci.c -o fibonacci
./fibonacci
```

On Windows with GCC/MinGW:

```bash
gcc fibonacci.c -o fibonacci.exe
fibonacci.exe
```

Enter a positive integer when prompted. For example, entering `7` prints:
`0 1 1 2 3 5 8`
