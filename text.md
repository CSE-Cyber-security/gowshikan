# Fibonacci Series — Project Notes

**Language:** C

**Aim:** To print the Fibonacci series for the number of terms entered by the user.

**Algorithm:**
1. Start.
2. Read the number of terms `n`.
3. If `n` is not positive, show an error and stop.
4. Set `first = 0` and `second = 1`.
5. Repeat `n` times: print `first`, calculate the next term, then update the two values.
6. Stop.

**Sample input:** `7`

**Sample output:** `0 1 1 2 3 5 8`

**Result:** The Fibonacci series is displayed successfully.
